# 🏏 IPL Data Analysis – Power BI Dashboard

> 📊 An interactive Power BI dashboard for exploring IPL seasons, team performance, and player statistics.

This project is built using **Microsoft Power BI** to analyze IPL data and present useful insights through an interactive and easy-to-understand dashboard.

The dashboard allows users to explore different IPL seasons and quickly compare teams, players, and tournament statistics.

---

## 📌 Project Overview

The dashboard provides a season-wise analysis of the IPL, covering important areas such as:

- 🏆 IPL Champions & Runner-up
- 🟠 Orange Cap holder & runs
- 🟣 Purple Cap holder & wickets
- 🔥 Top players for fours & sixes
- 💯 Centuries & half-centuries
- 🏟️ Number of venues
- 🏏 Total matches and teams
- 📈 Team-wise performance
- 🎯 Wins, losses, points and no-results

---

## 📊 Dashboard Highlights

### 🎯 Season Filter

A season slicer allows users to select a particular IPL season and dynamically update the dashboard.

### 🏆 Season Summary

The dashboard displays key tournament information for the selected season:

- 🥇 Champion
- 🥈 Runner-up
- 🏏 Total matches
- 👥 Number of teams
- 🏟️ Number of venues

### 👤 Player Performance

Player statistics include:

| Category | Description |
|---|---|
| 🟠 Orange Cap | Highest run scorer |
| 🟣 Purple Cap | Highest wicket taker |
| 🔥 Fours | Top players by number of fours |
| 💥 Sixes | Top players by number of sixes |
| 💯 Centuries | Players scoring centuries |
| ⭐ Half-Centuries | Players scoring 50+ |

### 🏏 Team Performance

The dashboard provides a comparison of teams based on:

- Matches Played
- Matches Won
- Matches Lost
- No Results
- Ties
- Total Points

This makes it easier to compare team performance within a season.
